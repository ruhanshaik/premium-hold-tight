# Premium Maintenance Page

Build a premium, professional maintenance / coming-soon website for my company.

Main Goal

The website should clearly communicate that the main website is currently being upgraded/maintained, while keeping the page visually impressive and professional.

I will provide:

My company logo — use the exact logo I provide.

An animation/video file — use the exact video I provide as the main visual element.

Design Direction  https://pin.it/32t9DKELl

Create a minimal, modern, premium corporate design.

Do NOT make it look like a generic AI-generated landing page.

Avoid:

Neon colors

Excessive gradients

Glassmorphism

Unnecessary animations

Excessive text

Stock images

AI-generated illustrations

Generic icons

Overly colorful backgrounds

Use a clean layout with strong typography, generous spacing and a professional corporate feel.

Hero Section

The first screen should immediately show:

[COMPANY LOGO]

Then a short headline:

We’re upgrading our digital experience.

Supporting text:

Our website is currently under maintenance while we work on something better. We’ll be back shortly.

Animation Video

Place the provided animation video prominently on the page.

The video should be the main visual focus of the page.

Requirements:

Use my exact uploaded video.

Do not replace it with another video.

Do not crop important parts of the video.

Maintain the video's original aspect ratio.

Make it responsive on desktop, tablet and mobile.

Use a clean, elegant container around the video if required.

The video should autoplay if supported.

Keep it muted by default.

Loop the video continuously.

Do not show unnecessary video controls unless required.

Make the video load efficiently.

Layout

Desktop:

Logo
↓
Headline
↓
Short maintenance message
↓
Large animation video
↓
Small contact section

Mobile:

Logo
↓
Headline
↓
Short message
↓
Animation video
↓
Contact information

Keep everything vertically balanced and centered.

Contact Section

At the bottom, add a simple line:

Need to reach us?

Then provide:

Email: [MY EMAIL]

Phone: [MY PHONE NUMBER]

Add simple buttons for:

Contact Us

WhatsApp

Use proper links for the email, phone and WhatsApp buttons.

Footer

Add a minimal footer:

© 2026 [COMPANY NAME]. All rights reserved.

Do not make the footer visually heavy.

Branding

The company logo I upload is the primary brand identity.

Use the logo's existing colors as the main brand colors.

Do not randomly introduce new brand colors.

If the logo has a dark/light version, choose the version that provides the best contrast with the background.

Typography

Use a modern, highly readable professional font.

Use:

Large bold headline

Medium-weight supporting text

Clean small text for contact/footer

Keep typography consistent throughout the page.

Background

Use a clean background that complements my company logo and animation video.

Prefer:

White

Off-white

Very light neutral tones

If the provided video works better on a dark background, create a sophisticated dark version instead.

Do not use a busy background.

Responsiveness

The website must look excellent on:

Desktop

Laptop

Tablet

Mobile

Pay particular attention to:

Video sizing

Logo sizing

Text wrapping

Vertical spacing

Button sizing

Mobile margins

Technical Requirements

Build this as a production-quality responsive website.

Ensure:

Fast loading

Optimized video loading

Responsive images/video

Semantic HTML

Good accessibility

Proper page title and meta description

No horizontal scrolling

No broken links

Clean component structure

Clean and maintainable code

Important

Do not create unnecessary sections.

This is a maintenance page, not a full marketing website.

The page should feel like a premium company temporarily unavailable — not like a template saying "Coming Soon."

Use my actual logo and actual animation video as the primary visual assets.

Before finalizing, check the entire page on desktop and mobile and make sure the visual hierarchy feels polished, balanced and professional. the video link has rovided ok.
